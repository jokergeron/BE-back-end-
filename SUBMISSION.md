Penjelasan Singkat Proyek:
Proyek ini adalah RESTful API untuk Sistem Manajemen Turnamen Esports. Dibangun menggunakan Python Flask dan database PostgreSQL (Supabase) yang di-deploy secara serverless ke Vercel. API ini mendukung operasi CRUD lengkap untuk data turnamen, filter status dan pencarian, proteksi integritas relasional terhadap data pendaftaran tim, serta endpoint data tim, pertandingan, dan registrasi. Seluruh fungsi telah diuji dengan 34 skenario automated testing dan terverifikasi via Postman / Thunder Client.
